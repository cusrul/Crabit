## 从这几样部件开始

已经拿到组装好的手表，可以直接跳到本页的“三个按键与菜单”，不用拆开设备。

这组照片记录了把配件展开、组装成手表，最后戴在手上的过程。先看清每部分的位置，再认识完整的 Crabit。

![展开的电池、主板、显示模组与橙色表带](/media/crabit/parts.webp)

主板承载芯片和接口；显示模组负责呈现界面；电池提供便携供电；表带用于固定和佩戴。
这是装配过程展示，不是要求购买成品的用户拆开手表，也不以照片代替出货清单。

## 戴在手上的样子

![佩戴 Crabit 后的表盘显示](/media/crabit/wearing.webp)

完成组装后，可以直接在手腕上查看时间和表盘信息。照片中的数值、样式是拍摄时状态，不代表每块手表的默认配置。
确认佩戴舒适、无裸露导体接触风险，再体验菜单和 App。

## 成品包含什么

手表本体、电池与表带。不含外壳，也不含充电／数据线。
这是电路板外露的版本，使用时避免水、金属短接、拉扯线材与接触裸露导体；
没有防水、防摔等级承诺。电池容量与续航待确认，不用休眠电流推算使用天数。

## 先玩本机功能

### 三个按键与菜单

以下方向以屏幕正对自己、文字正向时为准：

| 按键 | 操作 | 用途 |
| --- | --- | --- |
| 左上键 | 短按并松开 | 向上移动焦点 |
| 左下键 | 短按 | 向下移动焦点 |
| 右侧键 | 短按并松开 | 确认选中项；在表盘进入菜单 |
| 右侧键 | 长按约 0.6 秒 | STM32 界面返回上一层；也可选页面里的“返回” |
| 左上键 | 单独长按约 1 秒 | 开关后台 BLE，详见[连接 App](connect.md) |

先用物理按键熟悉操作，再尝试设置里的 PAT 触摸和 QMI 倾斜输入。没有开启对应输入或传感器暂不可用时，先用按键排除操作方式的影响。
BW16 独占应用有自己的退出流程，不能把这里的 STM32 返回键规则直接套用到所有 BW16 应用。

![正常菜单的本地 NanoUI 模型演示](/media/crabit/watch-menu.webp)

*模型运行实际 NanoUI 菜单；这是本地演示，不是实体屏幕直播。*

### 推荐体验顺序

1. 检查外观、电池连接和表带固定，没有明显损坏再上电。
2. 从表盘进入菜单，先体验“传感器”和“系统设置”。
3. 进入设置调整亮度与输入方式；未应用的草稿与已保存配置是两种状态。
4. BW16 应用是另一颗芯片的应用入口，按设备提示完成模式切换，
   不要在接管或烧录中途强制改变供电。

菜单和小游戏以本次实际出货固件为准。旧调试菜单或整个 Arduboy 游戏库
并不等于都预装或兼容。

### 调整设置后如何确认

在“系统设置 → 设置”修改亮度、输入与反馈等参数后，选择底部“应用”。手表显示“已应用”才表示保存成功；若显示“保存失败”，不要当成已保存。
蓝牙按钮是例外：按下立即发起开关，不必再点“应用”。第一次不要改供电或开发工具里的烧录选项。

## 然后连接 App

本机菜单不要求你先安装 IDE。需要配置和脚本编辑时，
继续阅读[连接配套 App](connect.md)。
连接后按[App 使用指南](app-guide.md)体验配置、时间天气和无害文本脚本。
第一次使用不要随意进入开发工具中的烧录入口。

## 出现异常时

记录最后一个菜单、操作顺序、提示文字与固件版本，停止反复切换模式。
通过交流群或直接联系开发者；具体售后、退换与响应承诺以正式商品说明为准。
更新或恢复前先读[固件与恢复](update.md)。
