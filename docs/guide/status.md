## 最近已由维护者确认的修改范围

- 电池供电下的 STOP2 误唤醒排查与 PAT EXTI8 处理；保留只读 RAM 唤醒诊断以便追溯。
- 蓝牙广播工具的 All / Android / iOS Device / iOS Action 选择。
- Wi-Fi 雷达显示探测地址、最近出现时间和探测次数，不再用帧数宣称距离或威胁等级。
- Hopper 的 QMI 倾斜输入、左右方向修正及英文画面。
- STM32 设置恢复单页，移除重复蓝牙入口，使底部应用可达；增加“永不”息屏及字形。
- STM32 保存的屏幕亮度经现有 UART 同步到 BW16。首次默认亮度为 20%，不覆盖已保存配置。

这些是维护者对近期修改的实机反馈，不代表所有历史 App、所有手机系统版本或新生成候选的完整压力验证。

## 当前默认功能与限制

| 项目 | 当前范围 | 限制 |
| --- | --- | --- |
| STM32 | STM32L432CBU6，256 KiB Flash；传感器、USB、低功耗和本机 NanoUI | KB/CB 型号与固件不可混用 |
| BW16 | Arduino IDE 默认 Wi-Fi 工具 + Hopper；独立 HTTPS 天气默认关闭 | 不将其他显式 lab profile 当成相同固件；镜像必须通过边界检查 |
| BLE | 六位应用验证码；快捷键开关，正常路径不执行历史 ATTACH/PAIR | 不是 OS bond 或 SMP 加密；公开初始码不能当秘密 |
| USB | CDC + 键盘、RAM 脚本 | 不宣称旧 Flash 脚本库、鼠标或全部异常插拔场景可用 |
| 天气与时间 | 由 Flutter 客户端获取并同步 | 无线模块不默认自行获取天气 |
| 设置 | 调整后点“应用”保存，直接返回丢弃草稿 | “永不”表示不因闲置息屏及进入 STOP2；蓝牙由快捷键操作 |
| Flutter | Android / Windows 客户端、本地脚本与数据、3D NanoUI 预览 | 模型屏幕不是实体屏幕实时镜像；IMU 基于加速度倾斜，没有绝对航向 |
| 审计记录 | BW16 → STM32 RAM → BLE → Flutter；两条，每条最多 768 字节 | 非完整抓包文件；断电丢失，不是云存储 |

## 发布与回退

下载说明对应已公开的旧预览版。后续候选应附固定源码 SHA、双端固件哈希、构建环境、客户端版本和未测范围，经维护者审核后才更新公开下载。

历史 ATTACH、QMI 实验和旧回退指纹仅用于追溯，不自动成为当前版本。固件烧录、复位、供电和设备操作由操作者完成。

## 文档不是验收替代品

能编译不代表实机通过；界面预览不能证明无线、USB、电源和传感器行为。复现入口见[构建说明](../reproduction.md)，功能操作见[手表使用指南](using-the-watch.md)。
