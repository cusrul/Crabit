## 当前默认 BW16 菜单与构建 profile

源码 `config.h` 默认开启：

```text
CRABIT_BW16_DIAG_ATTACH_TRACE = 1
CRABIT_BW16_DIAG_ATTACH_ADMISSION_ONLY = 1
CRABIT_BW16_DIAG_SMALL_APP_SET = 1
```

这些开关仍存在，但不能单独代表当前可见菜单：还须结合构建 profile。ATTACH admission-only 等旧诊断代码仍可在历史兼容路径中找到；它不是正常验证码方案的必经握手，也不是配对确认流程。
当前 IDE 默认构建由 `CrabitBuildProfile.h` 选择 Wi-Fi 工具 + Hopper 试验组合；其他显式 profile 不应与 IDE 默认混为一谈。独立网络同步默认关闭，天气从手机中继。

六位验证码是应用层本地验证门槛，不是 BLE SMP 配对或加密安全。详细边界见验证码候选说明。

## 历史 ATTACH 空间对照实验

缩减菜单后，实际 packed image 为 946176 字节（924 KiB），结束于 `0xED000`，距第一保留区 60 KiB。
对照镜像为 966656 字节（944 KiB），实际减少 20 KiB。静态 RAM 类段合计仅减少 128 字节；
没有在该实验中测得运行时剩余堆或栈高水位。

历史缩减菜单空间实验及 `ATTACH TIMEOUT` 记录仅说明当时路径的结果，不能作为当前验证码候选的阻塞或验收证据，也没有排除当时的运行时 RAM 问题。

收敛前 `8c7d7e0` 的字号候选构建记录为 packed image 999424 字节，物理结束地址 `0xFA000`，距保留区 `0xFC000` 为 8192 字节。它与上面的历史实验不是同一组合，不能混用数字；后续源码变更须重新编译和检查边界。

## 文档不是验收替代品

桌面测试证明所测契约在该主机环境的表现；编译证明所选源码与工具链完成构建；
镜像检查证明该文件没有跨越所配置的边界。三者都不能证明实体设备供电、OLED 交接、无线稳定性和 USB 枚举。
后续公开发布应单独标记成对固件 SHA、构建环境与操作者验收结果。
