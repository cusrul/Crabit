# 从零开始使用 Crabit 手表

本指南帮助你区分客户端界面、设备通信和真正的硬件功能。固件仍在开发中；开始前请先看[项目 README](../../README.md)与平台前置条件。不要假设手表上运行的固件与当前源码分支相同。

## 1. 运行手机/桌面客户端

安装 Flutter 与 Windows 桌面 C++ 工具链后，在仓库根目录运行：

```powershell
cd apps/mobile
flutter pub get
flutter run -d windows
```

这是客户端演示/开发入口，不会自动连接或更新手表。仓库虽有 Android、iOS、macOS、Linux、Web 工程目录，但各目标仍需分别构建、运行和验证。

## 2. 先认识本地预览

设备页的表壳、3D 模型和 OLED 画面是客户端本地渲染。Windows 上可以运行桌面 NanoUI 模拟器；模型上的按键会驱动模拟器输入，但模拟菜单不等同于真实硬件动作。模型查看页只查看本地静态资源。两者都不是手表屏幕镜像，也不要求连接手表。

## 3. 手表本机界面

当前 STM32 启动器保留 `极速连接`、`传感器`、`系统设置` 和 `开发工具`。
`BLE LINK`、`BLE MODE` 和旧协处理器测试终端已从菜单停用，源码保留。
在 STM32 正常 UI 中，左上角 PA7 长按约1秒切换后台蓝牙；一次长按只触发一次，
短按在松开时仍为向上导航，组合键不触发蓝牙。BW16 UI/烧录独占流程不接管此快捷键。
后台蓝牙启动只在当前 STM32 页面显示 `BLE STARTING` 小提示，不切换到逐阶段调试画面；失败原因仍通过小提示显示。
`极速连接` 仍沿原流程把 UI 交给 BW16。后台会话活动时，一些接管/烧录入口会提示 `STOP BLE FIRST`。
不要为绕过提示而强制切换电源或使用另一个入口。

普通设置位于 **系统设置 → 设置**，是单个可滚动页面：

| 项目 | 操作与含义 |
| --- | --- |
| Brightness | 百分比亮度；OK 进入/退出编辑，方向键调节，立即预览 |
| Invert | OK 切换反色，立即预览 |
| Screen off | 3/5/10/15/30 秒息屏；不提供“永不息屏” |
| Sleep + | 息屏后的额外等待：5/10/15/30/60 秒或 NEVER |
| Bluetooth | ON/OFF 立即切换运行中的蓝牙会话，下方显示实际状态；无需 APPLY，不更改开机自动启动配置 |
| APPLY | 应用这四项；没有变化时不重复写入 |
| BACK | 放弃未应用草稿，恢复已提交的显示配置 |

标题带 `*` 表示还有草稿。列表会跟随焦点滚动；返回在编辑中也可退出。
`CUSTOM` 表示现有配置不在选项中，不主动选择其他值就保留它。
`APPLIED` 表示调用既有配置保存路径，不是已验证 Flash 成功写入的证明。
当前无线调试候选可能强制保持唤醒，因此这些 UI 选项不能保证调试时实际休眠，需结合版本理解。

`传感器` 文件夹内的旧菜单文字“六轴姿态”等只是页面名称，不改变当前加速度数据路径的限制。
`开发工具` 涉及固件烧录和协处理器控制，不建议第一次体验时随意进入。
当前默认 BW16 UI 恢复图标轮播菜单，`PAIR DIAG`、`STATUS` 测试入口仍停用。
产品构建不链接大动画和实验 App：蓝牙栏目提示使用 STM32 设置，网络/游戏栏目明确提示未编入，系统栏目显示关于页；这不代表旧 HID/Wi-Fi/游戏功能已恢复或验收。

## 4. 连接与配对

仅在你准备好操作实体设备时，才从应用显式发起连接，并按当前固件提示在手表端确认。观察并分别记录扫描、连接、应用配对/认证和业务回显结果；其中任何一步成功都不能替代后续步骤。BLE UUID 或客户端令牌不是操作系统蓝牙绑定的证明。

**当前限制：** 旧候选后台 `ATTACH` 仍报告超时。新的 RAM/UART 候选
取消了自动 ATTACH，但尚待启动后 UART 实机验证；这一步请关闭客户端，不发起配对。
本指南不承诺后台连接、配对完成或数据传输可用。需要刷写/复位/上电时由用户亲自操作，并遵循候选卡。

## 5. 客户端页面能做什么

- **设备**：提供连接状态与诊断入口。只有收到对应设备业务响应时，才可称为读取成功；“已连接”不代表传感器、屏幕或所有命令正常。
- **设置**：界面控件不保证设备端支持或已保存。看见明确、匹配的业务响应再判断结果；传输 ACK 不等于业务操作成功。
- **无线记录**：提供记录/诊断界面，不代表 Wi-Fi 已连接、扫描或控制成功。
- **USB 工具**：脚本内容保存在手机本地，仅供编辑查看；当前固件禁用了 BadUSB 脚本执行器。不要尝试发送、存储或擦除命令。固件中的固定无害文本 USB 测试是单独的人工测试路径，不是通用 BadUSB 能力。
- **调试**：开发辅助界面，结果要结合固件版本、原始返回和验收条件解释。

本地脚本、偏好和诊断数据不是云端备份；清除 App 数据或卸载可能会删除它们。

## 6. 倾斜与 3D 朝向

当前倾斜路径由加速度/重力方向得到相对 roll、pitch。没有完整陀螺仪/磁力计航向数据，yaw 不代表真实方向；不要将其描述为完整姿态追踪。还需在目标硬件上验证坐标轴、方向和链路表现。即使模型随倾斜转动，它仍然是手机本地模型，而非实时屏幕镜像。

## 7. 安全与故障处理

- 不运行来源不明的键盘脚本，不发送攻击载荷；本项目没有启用通用脚本执行。
- 不将桌面模拟器画面当作固件验收，也不把历史分支结果当作当前固件证据。
- 遇到连接超时、屏幕异常或设备无响应时先停止操作，记录固件身份和界面提示；不要盲目重试、复位或刷写。
- 只有用户操作手表的供电、复位与刷写。桌面构建、Flutter 测试和源码检查都不能替代实机验收。
