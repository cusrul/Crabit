# 故障排查

先记录源码 SHA、实际烧录文件的 SHA256、两端固件组合、工具版本、屏幕原文和触发步骤。
把“编译失败”“界面异常”“广播消失”“业务超时”“重启后无法进入”分别描述，不合并成一句“蓝牙坏了”。

## Arduino 找不到 NanoUILegacy.h / NanoUI.h / CrabitNanoUI.h

先确认打开的是当前仓库 `firmware/rtl8720dn/NanoUI/NanoUI.ino`。
按[构建指南](build-and-flash.md)打包并安装当前共享库，检查 IDE 是否优先选择了旧的重复库。
历史分支可能使用不同库名或入口，不要拿新旧 README 混用。

不要将所有头文件复制进 sketch，更不要为此修改 SDK。CLI 验证应使用现有包装脚本，它会显式指定共享库。

## Arduino 找不到 radio_contract.h 等共享契约

这与 NanoUI 库是否安装是不同边界。先核对当前 sketch 的 `src/` 兼容入口、仓库结构与构建包装器，
确认没有只复制 `.ino` 到另一文件夹。保留完整检出，避免从其他历史 Goal 复制单个头文件来“修好”。
附上首个编译错误、源码 SHA 和完整编译命令；不是把最终 `exit status 1` 当作原因。

## IDE 显示没有超限，但镜像检查失败

检查对象应是实际 `km0_km4_image2.bin`，不是 sketch 汇总或调试 ELF。
本项目保留区比标称 2 MB 更早出现。停止烧录，保留失败报告；不要绕过边界检查、修改 SDK 分区或关闭保护。
`DO_NOT_FLASH.txt` 表示编译测量，不是可刷固件。见[硬件存储说明](hardware.md)。

## Windows 构建提示生成器/编译器不匹配

一个 CMake 构建目录只服务一套配置。另选新目录，例如 `build/first-app-ninja`，重新配置。
确认当前终端能找到选定编译器。不要删除不确定用途的其他工作目录，也不要把 ARM 交叉工具链套到 Win32 示例。

## 字体显示方框、缺字或图片不对

先检查消费 App 的 `nanoui-assets.json`、实际扫描目录、字号、输入字体覆盖和生成 `.cpp` 是否参与本次编译。
运行时动态文本可能不被扫描到；按[资源指南](assets.md)配置额外文本。
默认小 BDF 不包含所有中文字符，扫描到字符串并不会创造字形。不要手工拼接不同 App 生成的字库，也不要静默换系统字体掩盖缺字。

## 手机搜不到设备

先确认 BW16 确实上电、固件版本匹配且进入预期模式，再看屏幕提示。
BW16 断电时不能靠客户端扫描唤醒。Windows 蓝牙权限/适配器、服务过滤和设备状态也要分开记录。
不要把另一个 App 的 `ameba_*` 广播直接当作当前产品服务；名称、UUID 与固件必须一起核对。

## 有 ADVERTISING，但 ATTACH TIMEOUT

这是当前未解决的候选问题，不是正常配对步骤。启动前的模式命令成功，只证明那个阶段的 UART 路径；
BLE 初始化后仍可能在接收、分发、owner 处理或回包阶段出现问题。
不能因为“UART 曾经能启动 BLE”就排除后续 UART/任务路径。

缩减 App 的 20 KiB 镜像实验仍超时，没有证明纯容量就是根因，也没有证明问题已排除。
记录当前症状即可，不反复连接、清 bond、改 Flash 或循环复位来猜原因。见[状态与证据](status.md)。

## 进入 BW16 UI 黑屏，或连接后无法退出

先区分未启动、OLED 未交接、UI 卡住、无线启动卡住和重启后仍异常。
**“重启仍黑屏”本身不足以确认 Flash 损坏，但也不能忽略历史镜像/持久区边界风险。**
停止额外实验，保留固件身份、镜像边界报告、操作序列与已有日志，恢复只能由操作者在已知路径上执行。
不要用修改 AXP2101、延长随机延时或重写启动流程代替定位。

## COM 口不对 / USB 被占用

COM 编号不是固定配置，集成手表和独立 BW16 开发板也不是同一接线。
先辨认 STM32 USB、烧录桥和当前设备枚举；同一物理接口只交给一个程序。
关闭你明确知道正在占用它的监视器后再操作，不批量结束不认识的进程，不自动重置设备。

## 客户端保存了脚本，但设备没执行

当前只提供本机脚本编辑/保存；旧 BadUSB 执行器禁用。不是连接失败就应尝试绕过的功能。
USB 固定文本键盘测试是单独、安全受限的实验，不等于通用脚本运行时。
