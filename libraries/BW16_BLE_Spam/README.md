# BW16_BLE_Spam dependency

The Crabit maintainer supplied and authorized redistribution of this version
(1.0.0). Source-file MIT declarations and original author metadata are retained.
The added LICENSE reproduces the MIT terms; this dependency is not relicensed
under Crabit's GPL grant.

Crabit's CLI wrapper selects this checked-in library explicitly. No machine-local
Arduino sketchbook library directory is required. For Arduino IDE use, install
this directory as the BW16_BLE_Spam library in addition to the packaged NanoUI
library. Do not keep several conflicting copies installed.

This vendoring step changes dependency delivery only; it does not change radio
behavior or enable new tests on a physical device.
