# Crabit V1.2 打样包

[下载 Gerber ZIP：crabitV1.2.zip](crabitV1.2.zip?raw=true)

维护者于 2026-11-06 提供并确认此包已验证，可用于 PCB 打样。直接下载 ZIP，
上传至板厂的 Gerber 解析入口；下单前确认板厂预览中的铜层、板框、圆孔和槽孔。

## 内容

- 四个铜层：GTL、G1、G2、GBL。
- 顶底阻焊、丝印及焊膏层，板框和机械层。
- `Crabit_V2-RoundHoles.TXT`：圆孔钻孔文件。
- `Crabit_V2-SlotHoles.TXT`：槽孔钻孔文件。

V1.2 沿用维护者的包名；内部 `Crabit_V2` 文件名原样保留。此包为单独提供的制造输出，
并非本次从仓库 AD 工程重新生成；不据此宣称二者逐项一致。未新增 BOM 或贴片坐标，
板厚、铜厚和表面处理等下单参数不在本次发布中补填或推测。
