# Crabit Watch Mobile

Crabit 的 Flutter 客户端通过 BLE GATT 与 BW16 通信，并提供本地模型预览、设备页面和诊断工具。应用源码在 `lib/`；工程目录还包含 Android、iOS、Windows、macOS、Linux 和 Web 平台配置。存在平台工程目录不代表该平台当前已成功构建、运行或完成硬件验证。

## Windows 入门

安装 Flutter SDK 和 Windows 桌面构建所需的 Visual Studio C++ 工具链，在本目录执行：

```powershell
flutter pub get
flutter run -d windows
```

静态检查与客户端测试：

```powershell
flutter analyze
flutter test
```

这些命令检查本地客户端，不验证 BLE 实机链路。无需为普通启动刷写或复位手表；实体设备操作由用户执行。

## 客户端功能边界

- **审计记录中转候选**：BW16 经 UART 将少量记录暂存在 STM32 RAM，正常 BLE 产品连接后由 App 拉取、保存并确认。用户已确认人工记录和真实采集闭环跑通；容量、断电限制与尚未覆盖的验收见说明。

- **天气与校时**：App 获取天气并通过现有已认证 BLE 链路同步到 STM32 RAM；BW16 不再默认执行天气 HTTPS/NTP。支持城市搜索、手动坐标、缓存与失败保留；操作及实机边界见 App 天气同步。
- **本地 3D 与 NanoUI**：设备页的表壳是本地模型，屏幕显示的是模拟器帧，不是实体手表实时镜像。Windows 页面复用 STM32 `app_real` 菜单与产品页面；传感器、时间、天气和设置由内存演示服务提供，不连接真实硬件。无线和烧录入口仅作预览，不会操作设备；演示只使用手表现有的三个实体按键。
- **IMU 倾斜**：当前数据路径基于加速度/重力方向提供相对 roll/pitch；没有可用的陀螺仪/磁力计航向，yaw 不是真实绝对朝向，也不是完整姿态追踪。方向和实时无线表现仍需目标硬件验证。
- **本地数据**：Hive 保存应用本地脚本、BLE 验证码等连接辅助值和诊断记录，部分偏好也保存在本机。没有由这些功能提供的远程数据库同步承诺；清除应用数据或卸载可能导致数据丢失。
- **USB 工具**：本地脚本库与新的 RAM 键盘脚本候选，支持明确上传、确认运行、停止和读取状态，需要配套 STM32 固件。限制与实机步骤见 USB RAM 脚本。旧 Flash 执行器和存储/擦除命令仍未启用。
- **连接认证**：当前产品链路使用六位应用验证码，不再执行历史 PAIR/ALLOW 或 ATTACH。手表打开蓝牙后，App 连接并发送设备码；记住的是 App 本机保存的值，不是操作系统蓝牙绑定。设备码的配置与 App 保存码的更改步骤见 [连接图文](../../showcase/docs/connect.md)。验证码不提供 SMP 加密或抗监听、抗重放保证。

页面入口不是功能验收。连接成功不证明业务认证、设置写入、传感器、屏幕或其他子系统正常；传输 ACK 也不是设备业务结果。

输入/唤醒与反馈偏好、电池本地曲线、统一时间天气入口的新候选及验收步骤见
产品细节收敛候选。本轮不改变 BLE 启动、认证或硬件交接路径。

## 当前 BLE 候选限制

新 验证码候选沿用已实机通过的普通
`sys/mode=BLE` 广播与 UART 检查路径，以一次 `AUTH:<6 位数字>` 写入代替应用 PAIR/ALLOW。
用户已反馈本候选 UART PASS / RAM、菜单与基本客户端测试正常；逐项压力测试与 Wi-Fi 仍未记录。
旧 `PAIR_WAIT`、ATTACH 或历史 Flutter 结果不替代当前版本的功能验收。
验证码不等于 SMP/bond 或加密，不能抵抗监听/重放；细节见候选记录。历史背景见
BLE 回归记录与缩减 App 实验。

## 模型资源

Windows 原生闪退的捕获证据与可选兼容启动见故障记录。

当前静态模型资源位于 `assets/crabit_collection.glb`。原始 Blender 文件中的未保存修改不包含在导出资源里；导出器会在临时网格上烘焙世界坐标，不保存或修改源 `.blend`。屏幕纹理包含于 GLB；不要把模型朝向/装配细节解释为实际显示校准。导出脚本为 `tools/export_blender_collection.py`，仅在需要更新模型资源时使用。

Windows 使用工程已有的离线 3D 组件，无需手动复制模拟器 DLL 或运行时下载 CDN 资源。Android/iOS 等平台的 3D 行为仍需各自验证。

更多新手说明见[手机应用指南](../../docs/guide/mobile.md)与[手表使用指南](../../docs/guide/using-the-watch.md)。
