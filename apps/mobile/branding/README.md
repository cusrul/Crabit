# Application identity

Display name: Crabit. Internal package identifiers remain unchanged for data and upgrade compatibility.

`zzoo.svg` is the approved ZZOO website vector mark. `app-icon.png` places that mark on a light square background with padding; no generated replacement logo is used. Windows ICO and Android density assets are produced with `python tools/generate-app-icons.py` (Pillow).

Changing these files requires rebuilding the client; previously uploaded binaries do not change automatically.
